This web-app coded for individual assignment project

Software dependencies (testing):
1. Xampp (for apache and mysql)

For Installation, just follow these steps:

1. Copy all files from toolboxku_v3 to C:\xampp\htdocs\research-inventory\
2. Start Apache + MySQL in XAMPP
3. Open http://localhost/phpmyadmin and import db.sql (or run it manually)
4. Visit http://localhost/research-inventory/index.php


No npm, no build step, no terminal commands needed beyond XAMPP startup. The app runs directly.
